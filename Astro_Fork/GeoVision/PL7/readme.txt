Thanks for purchasing Parashara's Light 7.0

To Install the Program

1. Insert the Parashara's Light 7.0 CD in the CD Drive. 
   The installation program should launch SETUP.EXE automatically.
   If it does not launch, run SETUP.EXE from the CD.

2. If the software is supplied with a HASP key, a device driver is 
   required to run the program. To install the device driver click on
   icon 'Install HASP Driver'.
   
   OR run HDD32.exe from the Parashara's Light CD.

3. To run Parashara's Light 7.0 program click on icon 'Parashara's 
   Light 7.0' under the program group 'Parashara's Light 7.0'.

4. The first time you run the program, you will be required to enter 
   your name and a password. This password has to be obtained from 
   Parashara Software Pvt. Ltd.. Please supply your exact name, and system ID 
   given in the registration screen.

5. To read the Users Manual, click on icon 'Users Manual'. 
   This file is in Portable Document Format (PDF) and can be read 
   with Acrobat Reader. If you do not have the Acrobat Reader, it 
   is supplied in the Parashara's Light CD under \Acrobat directory.

6. Click on 'Uninstall' to uninstall the Parashara's Light 7.0.
