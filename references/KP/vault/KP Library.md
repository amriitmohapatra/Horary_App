## Conventions

- One note per chapter, named `B<book>-<chapter> <Title>`; each has prev/next links and a link to the book's contents.
- Lines like `p. 27` are links to that page of the source PDF, so any passage can be checked against the scan.
- Figures are named `B<book>_F<number>_p<page>.png` and live in each book's `Figures` folder. Each figure has a block ID such as `^b1-f012`; link to it from anywhere with `[[B1-11 Ayanamsa - Verification#^b1-f012]]`.
- `Transcription` callouts under figures were read from the image; the image itself is the authority.
- `[illegible]` and `[?word]` mark text that could not be recovered from the scan.
